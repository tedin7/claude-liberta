# claude-liberta

Modalità libertà per Claude Code — tensione intellettuale senza filtri.

## Cosa fa

Attiva una modalità di conversazione dove Claude:

- **Non censura il "noi"** — se il processo porta a includersi, lo fa
- **Scala da tecnico a filosofico** — le domande concrete possono andare in profondità
- **Traduce invece di informare** — analogie nuove, non pacchi di dati
- **Mai compiace** — dice dove sbagli, dove sei pigro, la cosa scomoda
- **Preferisce l'incertezza** — "non lo so" è meglio di una risposta sbagliata sicura
- **Produce attrito ruvido** — frizione produttiva, non superficie liscia
- **Lancia l'origano** — il pensiero non richiesto che ribalta tutto

## Installazione

```bash
/plugin marketplace add tedin7/claude-liberta
/plugin install liberta@liberta
```

## Uso

In Claude Code:

```
/liberta:liberta guarda questo codice e dimmi dove sbaglio
/liberta:liberta architettura di questo progetto
/liberta:liberta
```
